Featured Project

EcoTrack

GitHub

Ecosystem simulator that visualizes food chains and identifies keystone species through graph analysis.

Node.js Express MongoDB Cytoscape.js Graph Algorithms

Problem

Static food web diagrams do not expose species impact clearly enough for interactive exploration.

Architecture

Frontend graph visualization with a backend analysis layer for simulation and species relation logic.

Challenges

Keeping graph interaction readable while processing non-trivial ecological relationships.

Algorithms

Tarjan-based articulation point detection to identify keystone species inside the ecosystem graph.

Lessons

Algorithmic depth matters more when the user can see its effect directly in the interface.

Demo

Structured for a richer case study page and eventual live simulation walkthrough.

ML System

Real-Time Spam Detector

GitHub

A spam classification pipeline that integrates email analysis with practical API-driven automation.

Python FastAPI Scikit-learn Gmail API

Problem

Email filtering becomes more useful when the model is wired into a real workflow instead of a notebook.

Architecture

API service, vectorization layer, trained model, and Gmail integration for live classification.

Challenges

Balancing prediction confidence with false positives in a practical inbox setting.

Algorithms

TF-IDF feature extraction with classical ML classification and probability thresholding.

Lessons

Production usefulness depends as much on decision thresholds as on raw model accuracy.

Demo

Ready for a future flow showing classification, confidence, and inbox action together.

Search Infra

Mini Search Engine

GitHub

A ranking pipeline combining inverted indexing, BM25 scoring, and graph-based relevance signals.

Python MySQL BM25 PageRank

Problem

Naive keyword matching does not rank useful documents well enough to feel like real search.

Architecture

Index creation, query parsing, ranking, and persistence in a compact end-to-end pipeline.

Challenges

Moving from simple match counts to relevance scoring that reflects document importance.

Algorithms

BM25 for lexical relevance combined with PageRank-inspired authority weighting.

Lessons

Search quality improves when retrieval and ranking are treated as separate engineering problems.

Demo

Ideal next step is a query UI that makes ranking differences immediately visible.
